Platform Security Standards

DPDP Act Compliance

All user data is stored and processed in compliance with India's Digital Personal Data Protection Act 2023. No user data is shared with third parties without explicit consent.

Offline-First Storage

User profiles and session state are securely persisted using browser Local Storage and Session Storage, ensuring work is never lost even without internet connectivity.

Icon Policy — Lucide Icons Only

GrowUps follows a strict "no emoji" policy in all product UI. Only Lucide React Icons are used — aligning with international corporate design standards.

Admin CMS Security Gate

The Admin CMS is completely inaccessible without the Super Admin master password. All CMS changes are logged for audit purposes in Module 25 (Global Governance).
